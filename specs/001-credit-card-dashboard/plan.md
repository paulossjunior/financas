# Implementation Plan: Gestor Financeiro — Dashboard de Faturas BTG

**Branch**: `001-credit-card-dashboard` | **Date**: 2026-06-07 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-credit-card-dashboard/spec.md`

## Summary

Personal finance desktop app (Tauri v2 + Vue 3) that reads BTG credit card invoices (decrypted XLSX) from a local folder, parses transactions in Rust, and displays an interactive expense-category dashboard. Key flows: import invoice → auto-categorize → dashboard with biggest-spend highlight and monthly trend.

## Technical Context

**Language/Version**: Rust 2021 edition (1.75+) + TypeScript 5 + Vue 3.4+

**Primary Dependencies**:
- Rust: `tauri` v2, `calamine` 0.25+, `rust_decimal` 1.35+, `serde`/`serde_json`, `chrono`, `uuid`, `thiserror`, `tokio`
- Frontend: `vue` 3.4+, `vite` 5+, `pinia` 2+, `vue-echarts` 7+, `echarts` 5+, `@tauri-apps/api` v2, `vitest` 2+, `@vue/test-utils` 2+
- Dev: `playwright` (E2E via Tauri), `@tauri-apps/cli` v2

**Storage**: In-memory during session (no database for MVP). App config + category rules persisted as JSON in Tauri app data dir via `tauri-plugin-store`.

**Testing**: `cargo test` (Rust unit + integration), Vitest (Vue components), Playwright via Tauri test runner (E2E)

**Target Platform**: Desktop — macOS (primary), Linux, Windows via Tauri v2

**Performance Goals**: Dashboard renders < 5s after import, XLSX parse < 2s per file (files ≤ 5MB typical)

**Constraints**: Fully offline. No network calls. Personal data never leaves the machine. BTG files must be decrypted before import (MVP constraint).

**Scale/Scope**: Single user. Up to 24 XLSX invoice files (~500 transactions total). No concurrency requirements.
